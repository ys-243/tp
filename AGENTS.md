# Repository agent instructions

## Required Java coding standard

Read and follow
[seedu-java-coding-standard](.agents/skills/seedu-java-coding-standard/SKILL.md)
whenever writing, modifying, or reviewing Java code in this repository. This
requirement applies to all production code, tests, and test helpers. Keep all
new and modified Java code compliant and correct existing violations when
encountered in the code being worked on.

Run the skill's applicable checks before completing Java changes. Review rules
that Checkstyle cannot enforce manually; a passing build alone is insufficient.

## Required Git conventions

For every future commit in this repository, read and follow
[seedu-git-standard](.agents/skills/seedu-git-standard/SKILL.md) before
preparing the commit message or running `git commit`. This includes amendments
and agent-authored merge, squash, and revert messages. Apply the skill's branch
naming rules when creating branches as well.

Check the staged diff and final commit message against the skill before
committing. These instructions do not themselves request a commit, push, or
history rewrite.
